# NBA Data Analysis

This project analyzes NBA team statistics to identify factors related to team success.

## Dataset
NBA dataset from Kaggle (team stats including wins, shooting percentages, etc.)

## Project Structure
- data/ → dataset files
- notebooks/ → analysis notebook
- src/ → helper scripts

## How to Run
Open the notebook in the notebooks folder and run the cells.
